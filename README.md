# CSP Booking Brief — New Connection Journey

Product brief for the Wiom Partner App new-connection booking flow: how a partner
receives a booking, accepts it, and — when he can't do it — reports why in a way
we can act on.

`index.html` is a self-contained page, published at
https://saadbeg-pixel.github.io/csp-booking-brief/

Covers the objective, the 10–25 August failure analysis, the free-before-accept /
costs-after-accept principle, an interactive end-to-end flow map, the eight flows,
the reason and exit tables, edge cases, measurement plan, and open decisions.

**Internal-facing.** Contains Wiom performance metrics, SLA policy and partner payout
figures. The page is excluded from search engines (noindex + robots.txt), but anyone
with the link can read it. Share deliberately.
